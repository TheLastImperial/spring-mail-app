# Changes

Changes to version 1.0.0

## Mails Allows

New table to know what email is allowed to send it, this is a optional feature that can be activate
with the property `com.thelastimperial.mail.mails.blockNotAllows`, this is a auditable feature too.

## Resend mail.

Added logic to resend mail when a error happend.
Added feature to retries all by action error.

## Paths and layout

Updated paths.
Created main layout to be used for all the views.

## Migrate Auth to OAuth Client.

Added parameters to authenticate with OAuth Client.

## Documentation

Added Readme to the modules and JavaDoc comments.
